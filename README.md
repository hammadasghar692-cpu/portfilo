# Hammad Asghar Portfolio

Static site: HTML, CSS, vanilla JS, GSAP, ScrollTrigger, Lenis.

## Run
`npx serve .` (ES modules need a server, not file://)

## Before launch
1. Replace `YOUR_USERNAME` in `js/utils.js`, `build.py` and sitemap/robots.
2. Replace `FORM_ID` in contact.html with your Formspree form id.
3. Add `assets/images/og-image.jpg` (1200x630).
4. Edit pages with `python3 build.py` or directly in the .html files.

## Deploy
Push to GitHub, enable Pages (Source: GitHub Actions).
